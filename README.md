# Scam Detection AI Lab

Локальная лаборатория для тестирования диалогов, транскрибации аудио и обучения baseline-классификатора.

## Что умеет

- Проверяет текстовые диалоги на русском и казахском.
- Принимает аудио файлы WAV, MP3, M4A, OGG и FLAC.
- Записывает голос прямо с микрофона в браузере.
- Распознаёт аудио через faster-whisper (multilingual Whisper).
- Даёт вручную исправить транскрипт перед анализом.
- Сохраняет размеченные тексты в `data/dialogues.csv`.
- Обучает TF-IDF + Logistic Regression и сохраняет модель в `models/scam_model.joblib`.

## 1. Установка на Windows

Рекомендуется Python 3.13 (он совместим с приложением и аудио-зависимостями). Самый простой вариант — запустить `START_WINDOWS.bat`. Перед первым запуском установи runtime командой `py install 3.13`, затем закрой и снова открой PowerShell. Он создаст окружение, установит основные и аудиозависимости, затем запустит сайт. Для ручной установки открой PowerShell в папке проекта:

```powershell
py -3.13 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
```

Если PowerShell запрещает активацию окружения, только для текущего окна:

```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
.\.venv\Scripts\Activate.ps1
```

## 2. Запуск сайта

```powershell
streamlit run app.py
```

Откроется локальный адрес, обычно `http://localhost:8501`.

## 3. Подключить распознавание аудио

```powershell
pip install -r requirements-audio.txt  # включает совместимую версию av==18.1.0
```

Если запускал `START_WINDOWS.bat`, аудиозависимости уже установлены. При ручной установке выполни команду ниже или запусти `INSTALL_AUDIO.bat`. При первом распознавании Whisper скачает веса выбранного размера. После скачивания распознавание выполняется локально. Для ноутбука со слабым CPU начни с `tiny` или `base`; `small` обычно требует больше времени и памяти.

## 4. Запись с микрофона

Во вкладке **Аудио-тест** выбери блок записи и разреши браузеру доступ к микрофону. Используй `localhost`, не открывай сайт как обычный файл `file://`. Если браузер уже заблокировал микрофон, включи разрешение для `localhost` в настройках сайта.

## 5. Как добавлять данные и переобучать

В датасете должны быть колонки:

```csv
text,label
"Звонящий просит сообщить код из SMS",scam
"Курьер сообщает время доставки",legitimate
```

Допустимые метки:
- `scam` — мошеннический сценарий, подтверждённый или проверенный разметчиком.
- `legitimate` — обычный легитимный разговор.

После добавления примеров открой вкладку **Обучение** и нажми **Обучить / переобучить модель**. Можно также выполнить:

```powershell
python train.py
```

В проект входят исходные 70 демонстрационных примеров и ещё 92 сбалансированных искусственных примера в `data/curated_training.csv`. Дополнения расширяют сценарии мошенничества и безопасные похожие разговоры на русском и казахском, в том числе несколько ошибок распознавания речи. При обучении одинаковые примеры удаляются; текущая обучающая выборка содержит 160 текстов. Эти данные помогают проверить функции и не доказывают точность на реальных звонках. Снимок метрик и ограничения описаны в `MODEL_CARD.md`.

## 6. Как устроена модель

Поток выглядит так:

`Audio -> Whisper STT -> corrected transcript -> TF-IDF word/character features -> Logistic Regression -> experimental Threat Score`

То есть первая версия учится классифицировать текст расшифрованного диалога. Это не обучение собственной акустической модели и не большая языковая модель с нуля. При этом классификатор действительно обучается на тех метках, которые ты добавляешь.

Явная просьба продиктовать одноразовый код, пароль или CVV дополнительно повышает Threat Score. Распознаётся и известная ошибка транскрибации «кота» вместо «код», когда рядом есть просьба продиктовать или прочитать секрет.

Threat Score — экспериментальный внутренний рейтинг, не вероятность мошенничества. Не используй его как единственное основание для блокировки, обвинения или других важных решений.

## 7. Важные ограничения и приватность

- Приложение не получает аудио обычного SIM-звонка Android.
- Запись в браузере требует явного разрешения микрофона.
- Аудио по умолчанию не архивируется; после распознавания в датасет вручную сохраняется только текст.
- Для настоящих записей заранее проверь правовое основание и необходимость уведомления/согласия участников.
- Удаляй из примеров имена, номера телефонов, адреса, банковские данные, пароли и SMS-коды.
- Не добавляй реальные приватные аудио и датасеты в публичный GitHub.

## Размещение на Vercel

В репозитории сохранена исходная локальная версия Streamlit с аудио, датасетом и обучением. Для Vercel добавлен отдельный лёгкий веб-интерфейс: он проверяет текст диалога на русском и казахском языках через `api/analyze.py`. Перед публикацией Vercel обучает модель из демонстрационных CSV и добавляет собранный файл в serverless-функцию.

Из-за бессерверной модели Vercel эта веб-версия не загружает и не расшифровывает аудио, не хранит изменяемый датасет и не переобучает модель. Введённый текст не записывается приложением в файл или базу данных. Результат — экспериментальная оценка, а не доказательство мошенничества и не вероятность преступления.
